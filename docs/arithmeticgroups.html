get_word_rep(x)[source]¶
level¶

Compute generators of the subgroup Gamma_0(N), where N is the specified level.

Write down representatives of the cosets for Gamma_0(N) in Gamma(1), which we identify with P^1(O_F/N). We already have code to compute with this: namely, cusp_reduction_table does precisely this.

ALGORITHM :

Retrieve the cusp reduction table. Recall that this is a dictionary with keys given by tuples (a,c) representing the element (a:c) in P^1(O_F/N). The entries are C, A, where c is the corresponding cusp (from cusp_set) and A is a matrix taking C to a matrix with bottom row (a:c). Generate the coset representatives: this is given by taking A*C as we range over all (A,C) in the values of cusp_reduction_table coset_reps is now a dictionary: keys are elements of P^1(O_F/N), and values are matrices which are coset reps for Gamma_0(N) in Gamma(1) cor. to these elements.

Quaternion orders (PARI)¶

Quaternion algebras and their orders through PARI.

This module replaces the Magma functionality used by the arithmetic groups: maximal and Eichler orders, local splittings adapted to an order, elements of prescribed norm or minimal polynomial, and (through Rickards’ library, see darmonpoints.afuch) fundamental domains and presentations of arithmetic Fuchsian groups.

Orders are represented by square integer matrices whose columns are the coordinates of a ZZ-basis of the order in terms of the ZZ-basis of the maximal order stored by PARI’s alginit (this is the convention of afuchinit).

EXAMPLES:

sage: from darmonpoints.quatorder import QuaternionAlgebraPari
sage: QA = QuaternionAlgebraPari(QQ, -1, 3)
sage: QA.B
Quaternion Algebra (-1, 3) with base ring Rational Field
sage: QA.B.discriminant()
6
sage: M = QA.eichler_order_matrix(5)
sage: M.det()
5
sage: O = QA.order_basis(M)
sage: QA.is_in_order(M, O[2] * O[3])
True

A local splitting adapted to the Eichler order:

sage: (I, J, K), phi = QA.local_splitting(M, 5, 1, 20)
sage: I**2 == -1 and J**2 == 3 and I * J == K and J * I == -K
True
sage: iota = QA.local_embedding_function((I, J, K), phi)
sage: all(iota(o).apply_map(lambda t: t.valuation() >= 0) == matrix(2, 2, [1]*4) for o in O)
True
sage: all(iota(o)[1, 0].valuation() >= 1 for o in O)
True

Elements of given norm and given minimal polynomial:

sage: x = QA.element_of_norm(M, 7)
sage: x.reduced_norm().abs(), QA.is_in_order(M, x)
(7, True)
sage: y = QA.element_with_minpoly(QA.maximal_order_matrix(), 1, 5)
sage: y.reduced_trace(), y.reduced_norm()
(1, 5)

Arithmetic Kleinian groups¶

Fundamental domains and presentations of arithmetic Kleinian groups.

This is a Python port of Aurel Page’s Magma package KleinianGroups 1.0 (see darmonpoints/KleinianGroups-1.0; GPL-3), restricted to what darmonpoints needs: the NormalizedBasis algorithm with the “SmallBalls” enumeration and the “Reduction” pairing method, for the norm one group or the unit group of an order, and the Presentation routine.

Reference: A. Page, Computing arithmetic Kleinian groups, Math. Comp. 84 (2015).

Points of hyperbolic 3-space are in the unit ball model, represented (as in Page’s code) by Hamilton quaternions x0 + x1*i + x2*j (the k coordinate is zero). Real numbers are gmpy2.mpfr with a working precision given in decimal digits, and quaternions are 4-tuples of them.

The arithmetic input is described by KleinianOrderData, which only needs the quaternion algebra B over a number field with exactly one complex place (B ramified at all the real places), a ZZ-basis of the order and a membership test.

EXAMPLES:

The maximal order of the quaternion algebra over QQ(sqrt{-7}) ramified at the two primes above 2:

sage: from darmonpoints.kleinian import *
sage: from darmonpoints.quatorder import QuaternionAlgebraPari
sage: from darmonpoints.util import quaternion_algebra_invariants_from_ramification
sage: F.<w> = NumberField(x^2 - x + 2)
sage: P, Q = [P for P, _ in F.ideal(2).factor()]
sage: a, b = quaternion_algebra_invariants_from_ramification(F, P * Q, [])
sage: QA = QuaternionAlgebraPari(F, a, b)
sage: M = QA.maximal_order_matrix()
sage: data = KleinianOrderData(QA.B, QA.order_basis(M), lambda x: QA.is_in_order(M, x))
sage: res = normalized_basis(data, pr=40, seed=1)
sage: abs(res['volume'] / res['covolume'] - 1) < 10^-10
True
sage: gens, rels = presentation(res['faces'], res['finite_edges'], data, res['ctx'], res['embedding'])
sage: words = [prod(gens[abs(i) - 1]**sign(i) for i in r) for r in rels]
sage: all(g == g.conjugate() for g in words)  # relations hold up to the centre
True
sage: new_rels, images, preimages = simplify_presentation(len(gens), rels)
sage: len(preimages) <= len(gens)
True
